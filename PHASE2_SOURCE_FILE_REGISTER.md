## 1. Overview & Forensic Principle

This register catalogues every file currently residing in `server/data/raw/` and `server/data/cache/`. In accordance with forensic audit requirements, this document distinguishes between:
1. **Actual Origin:** Whether the file was downloaded as a genuine binary/raster asset from an external agency portal, or generated locally on disk by project TypeScript scripts.
2. **Cryptographic Checksum:** The 64-character SHA-256 hash verifying local file storage integrity.
3. **Scientific Status Classification:** `DEMONSTRATION`, `MODELLED`, or `UNVERIFIED`.
