## 3. Detailed Recalculation Methodology & Code Traces

### 3.1 Recalculating the GRACE Trend
In `gracePipeline.ts`, `computeGraceStats()` performs linear regression over observed months:
$$\text{trend} = \frac{n \sum (xy) - \sum x \sum y}{n \sum (x^2) - (\sum x)^2}$$
- When evaluated over the 120 observed months for Ludhiana, the formula yields exactly **-2.84 cm/year**.
- **Forensic Audit Finding:** This trend is computationally sound, but its inputs were generated by:
  $$\text{TWS}_t = -16.5 + (-2.75 \times t) + 4.8 \sin(\dots) + \text{noise}$$
- Therefore, the linear regression is recovering the synthetic generator's slope parameter ($-2.75$) perturbed by pseudo-random noise and the 11-month mission gap. It does not represent an empirical observation from NASA satellite telemetry.

### 3.2 Recalculating GPM Annual Rainfall
In `rainfallPipeline.ts`, `computeRainfallStats()` evaluates:
$$\text{Annual Average} = \frac{\sum_{i=1}^{132} \text{rainfall}_i}{11\text{ years}}$$
- For Ludhiana, the sum of all 132 generated monthly values is $7,276.5\text{ mm}$, yielding $\frac{7276.5}{11} = \mathbf{661.5\text{ mm/year}}$.
- **Forensic Audit Finding:** This matches the reported number exactly. However, each monthly value was generated as a percentage of `profile.annualMeanMm` multiplied by `interannualAnomaly` and modulated by sinusoidal noise. It was not derived from NASA IMERG gridded satellite rasters.

### 3.3 Recalculating Monitored Well Decline Rates
In `wrisImportPipeline.ts`, `computeWellStats()` evaluates:
$$\text{Decline Rate} = \frac{\text{Pre-Monsoon 2024 Depth} - \text{Pre-Monsoon 2014 Depth}}{10\text{ years}}$$
- For Ludhiana:
  $$\text{Decline Rate} = \frac{34.6\text{ mbgl} - 26.5\text{ mbgl}}{10\text{ years}} = \mathbf{+0.81\text{ m/year}}$$
- **Forensic Audit Finding:** The calculation is mathematically correct, but operates on hardcoded array elements authored in `wrisImportPipeline.ts` for station `W-PB-LUD-012`, an unverified identifier.
